I read both notebooks, the LAMMPS inputs and submit scripts, and the two 8000 K runs. I also refit both runs at the known drive frequency of 1 THz. The runs look sound. The notebook analysis has several problems that change the viscosity numbers.

**Setup as I read it.** MgO has 4096 atoms at 6.6868 Å³/atom, which is about 190 GPa at 8000 K. The runs use a DeePMD potential with fix deform wiggle plus nvt/sllod. The period is 1 ps.
- The R1A1 run wiggles the box length along x with a 1 Å amplitude, a strain of 3.3%.
- Run 54671682 wiggles the xz tilt with a 0.2 Å amplitude, a shear strain of 0.66%.

**My refit results** come from a least-squares fit of sine, cosine and a linear drift to stress and strain:

| Run | Modulus storage / loss | Phase δ | Loss modulus / ω |
|---|---|---|---|
| Uniaxial x | M′ = 538 GPa, M″ = 89 GPa | 9° | 0.0142 Pa·s |
| Shear xz | G′ = 15 GPa, G″ = 43 GPa | 70° | 0.0068 Pa·s |

Splitting each run into five blocks gives a scatter of about ±3% for the uniaxial run. The shear run scatters about ±20%.

**Problems in the notebooks:**

2. **Shear strain is not normalized.** The shear notebook uses the raw xz tilt in Å as strain. It needs to be divided by the box height, about 30.14 Å.
3. **Viscosity formula is incomplete.** It divides a stress FFT amplitude by frequency. It leaves out the strain amplitude, the 2π, and sin δ. The correct form is η′ = G″/ω with G″ = (σ₀/γ₀) sin δ. A forward-normalized FFT peak is also only half the amplitude.
4. **Phase is biased.** Getting the phase from the correlation coefficient pushes δ toward 90° when noise is present. In the shear run the noise per sample is about three times the signal. The lock-in fit avoids this bias.
5. **Uniaxial does not give shear viscosity.** Stretching along x changes the volume. That run measures the longitudinal modulus M = K + 4/3 G, and its loss gives ζ + 4/3 η. Combined with the shear run, the bulk viscosity ζ comes out at about 5 mPa·s.
6. **Shear data file is truncated.** The shear run's data file stops at step 246400, but the log shows all 500000 steps finished. The thermo extraction probably broke on a mid-run message.

**On the physics.** At 1 THz the shear response is still clearly viscoelastic. G′ is about 15 GPa, so ωτ is about 0.35. The 1 THz η′ is therefore below the zero-frequency viscosity, and a frequency sweep is needed to reach the Newtonian limit.

G(t) yields G*(ω) at all frequencies at once, which is the quantity Gross's spectra are built on. I'd use that as the main tool and keep a few wiggle runs as cross-checks.
